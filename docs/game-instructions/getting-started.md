# Getting started

The native client includes a board preview and an M04 turn-engine testing harness. Follow [Building](../building.md), then run scripts/dev.ps1. Wheel zooms, right-drag pans and left-click inspects. Right-click opens seed/setup, Fit board and Turn engine test; F4 opens the test directly. The native Close control exits.

See [Base turn engine](../base-turn-engine.md) for actual testing steps and limitations. Complete offline games arrive at M06, private lobbies at M08, and reliable online matches at M09. Solo will use one local human plus bots. These are planned modes, not the synthetic-seat test.
