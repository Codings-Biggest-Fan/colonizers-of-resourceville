# Getting started

M03 provides a native base-island layout preview. Follow [Building](../building.md), then run scripts/dev.ps1. Wheel zooms, right-drag pans and left-click inspects. Right-click opens seed/setup and Fit board. The native Close control exits. There are no playable games yet; see [Board preview](../board-preview.md).

## Planned gameplay

Offline games arrive at M06, private lobbies at M08, and reliable online matches at M09. Planned offline setup chooses total seats, human/bot seats, map, and rules. Solo uses one local human plus bots. Initial games support 2–4 seats, with larger supported games planned at M14.

Planned private-room setup includes a guest name, room code, settings, seats/colors, and readiness. Gameplay edits clear readiness; starting freezes the validated configuration. These are plans, not controls in M03.
