# Variants and expansions

**All gameplay is planned.** No variant is playable in M00.

| Mode | Target | Distinction |
| --- | --- | --- |
| Base offline | M06 | 2–4 seats; casual two-seat uses base rules |
| Custom settings | M10 | Standard versus visibly marked custom rules |
| Citadels & Sentinels | M11 | Knights, commodities, improvements, progress cards, barbarians |
| Open Seas | M12 | Ships, islands, exploration, scenario goals |
| Combined Open Seas/Citadels & Sentinels | M13 | Documented compatible scenarios only |
| Expanded players | M14 | Official 5–6 versus custom 7–8 presets |
| Caravans & Raiders | M15 | Core variants/scenarios; official two-player is separate |
| Voyagers & Corsairs | M16 | Distinct economy, cargo, and missions |
| Maps/combinations | M17 | Validated maps and supported combinations |

Incompatible options cannot start. Each selectable mode requires implemented rules/UI/bots. See [compatibility](../compatibility.md) and [pregame catalogue](../pregame-options.md).
