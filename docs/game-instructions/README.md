# Game Instructions

M01 offers a native foundation preview. Launch it with scripts/dev.ps1 after following [Building](../building.md). Resize the window and close it with Close preview or the native window control. The emblem is decorative; no board or game is implemented yet.

There are no setup, turn, trade, bot, save, room, or expansion controls in this revision. The server /health endpoint is process liveness only. The pages below describe planned guide coverage and must not be read as available gameplay.

M02 adds library-only [configuration contracts](../configuration-contract.md) and [rule/source inventories](../rules.md); these do not enable controls in the native preview. M21 plans final website/wiki completion after the game release.
