# Milestone screenshot evidence

[Roadmap](../ROADMAP.md) · [Record conventions](../milestones/README.md)

Use photos/milestone-NN/ for real native application screenshots. Each index records image, capture date, build/revision, dimensions, display scaling, scenario, and inspection result. Use sequential descriptive PNG names and preserve earlier evidence.

Capture only the selected game window or its own rendered frame. Use synthetic identities; exclude secrets, personal data, and unrelated windows. Store original game art under assets/ instead.

Material visual corrections need before/after evidence when possible. Multiplayer changes need paired client views. Explain missing before evidence or why a nonvisual milestone has no screenshot.

**Current state:** [M01](milestone-01/index.md) contains inspected native foundation captures. M02 changes contracts and documentation only, so its index explains why no new capture applies. Later indexes remain planned. M21 will label website/wiki captures separately from native gameplay evidence.
